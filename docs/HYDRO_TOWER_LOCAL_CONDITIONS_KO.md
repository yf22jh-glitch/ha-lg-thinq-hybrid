# 하이드로 타워 로컬 조건과 남은 시간 표시

## 0.12.2 변경

- 기능 DB의 `control_conditions`를 HA 선택지·사용 가능 표시와 로컬 명령에서
  함께 사용한다. 제품 전원, 현재 모드, 무드등 상태 등의 실제 자체 보고를 읽는다.
- 청정 전용에서는 가습·가습청정으로 원격 복귀하지 못하는 제품 조건을 유지한다.
  목표 습도와 포근한 가습은 청정 전용에서 사용할 수 없다.
- 가습 카드도 전원·모드·현재/목표 습도의 로컬 자체 보고를 우선 사용한다.
- 꺼짐 예약의 실제 남은 시간이 60→59분으로 바뀌어도 `unknown`으로 만들지 않는다.
  현재 남은 시간은 표시 전용이며 새로운 전송 가능 예약값으로 추가하지 않는다.
  예약 취소와 기존 예약값은 기존 로컬 명령을 사용한다.

DB 조건·문구·활성화와 교체형 기능 파일 변경은 기존 실시간 반영 경로를 사용한다.
통합 Python 실행부 자체를 업데이트하는 이번 릴리스에는 HA 재시작이 필요하다.
DB, 인증정보, 기기 연결 설정, 누적 전력 데이터는 통합 코드 폴더 밖에 보존한다.

## 배포와 확인

배포 정본은 Git의 `main`에서 만든 GitHub Release이며 설치는 HACS로 한다.
소스 수정본을 커밋하지 않은 채 운영 업데이트 원본으로 남기지 않는다.

검증은 실행 조건의 DB 반영·전송 거부·선택지 제외, 가습 카드의 로컬 상태,
남은 시간 표시와 표시 전용 선택의 무전송, 기존 명령 경로 회귀 테스트로 한다.
실기 명령·기기 ACK·자체 상태 대조는 로컬 브리지 저장소에서 수행하며,
기기 식별자와 패킷 캡처는 Git에 포함하지 않는다.
